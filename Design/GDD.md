# Leo Game — Game Design Document (v0.1)

> Черновая версия. Фиксирует решения, принятые на старте разработки. Будет дополняться по ходу работы над вертикальным срезом.

## 1. Концепт

Линейный экшен-платформер в sci-fi/техно-сеттинге. Игрок поровну проводит время в платформинге и в бою — уровни построены так, чтобы обе механики чередовались и усиливали друг друга, а не были фоном друг для друга.

**Референсы по структуре** (не по арту): линейные экшен-платформеры с уровнями и боссами в конце (Hollow Knight/Celeste — по ощущению точности платформинга и боя, но без метроидвании — прогресс уровень за уровнем, без бэктрекинга и открывания карты).

## 2. Сеттинг и сюжет

**Сеттинг:** sci-fi/техно.

**Протагонист — Leo.** Наёмник/агент, выполняет задания за плату/по контракту (детали нанимателя — открытый вопрос, не критичен для вертикального среза).

**Антагонист (уровень 1 / первый босс):** восставший ИИ и его машины. Leo зачищает объект/зону, захваченную вышедшим из-под контроля ИИ; на уровне встречаются его дроны/турели/боевые машины, в конце — босс, представляющий силу этого ИИ (тяжёлый боевой робот или его "аватар").

## 3. Core-геймплей

Бой и платформинг — равнозначные столпы; уровень должен регулярно переключать игрока между ними, а не давать длинные однородные секции одного из двух.

### 3.1 Движение
- Бег, прыжок — база.
- **Дэш/рывок** — быстрое горизонтальное ускорение/уклонение, вероятно с i-frames на активной фазе (уклонение от урона).
- **Двойной прыжок** — дополнительная вертикальная мобильность.
- Дэш и двойной прыжок доступны с старта (не пороги-открывашки в вертикальном срезе — упрощает первый прототип; вопрос про progression/unlock-систему — открытый).

### 3.2 Бой
- **Смешанный тип атаки:** ближний бой (клинок/кулак) + дальний (бластер/пистолет). Игрок переключается между двумя способами атаки.
- Комбат должен работать в связке с движением: дэш как часть комбо/уклонения, двойной прыжок для вертикального позиционирования в бою.

## 4. Структура уровней (vertical slice)

Объём первой играбельной версии: **1 уровень + 1 босс**.

- Уровень — линейный, чередует секции платформинга и боевые арены/стычки с дронами/машинами ИИ.
- Босс — в конце уровня, отдельная арена, финальный "экзамен" на связку движения + боя, наработанную по уровню.

## 5. Арт и звук

Placeholder-графика на старте (базовые спрайты/примитивы), финальный арт — позже.

**Визуальный референс протагониста (получен 2026-07-28):** sci-fi наёмник — жёлтые волосы, очки/гогглы, оранжево-чёрный костюм, механические поножи/наручи, двойное вооружение — винтовка/бластер (дальний бой) + большой клинок/меч (ближний бой). Хорошо ложится на уже согласованный микс ближнего+дальнего боя (раздел 3.2). Референс — готовое чужое изображение, не для прямого копирования/трассировки — ориентир по силуэту, палитре (оранжевый/чёрный/белый/металлик) и составу снаряжения при заказе/отрисовке финального арта.

## 6. Открытые вопросы (для следующих итераций)

- Наниматель Leo / более детальная сюжетная мотивация.
- Есть ли прогрессия/открытие способностей или всё доступно с начала игры.
- Управление: клавиатура+мышь / геймпад — оба, приоритет.
- Визуальный референс/арт-стиль для sci-fi сеттинга.
- Количество уровней/боссов после вертикального среза (полный объём игры).
